# SophiMarket V2

Projet Minecraft 1.21.1 NeoForge pour reconstruire le Market et le système de métiers côté client/serveur.

## Objectifs V2
- Market : Acheter / Vendre / Métiers / Enchantement & Réparation
- Métiers avec petites icônes cliquables côte à côte
- Mineur, Fermier, Chasseur, Alchimiste
- XP visible et progression par métier
- Récompenses avec icône, nom et prérequis
- Récompenses récupérables dans l'inventaire
- Quêtes du jour
- Synchronisation client/serveur

## Version
- Minecraft 1.21.1
- NeoForge 21.1.x
- Java 21
